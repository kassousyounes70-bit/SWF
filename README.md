# تطبيق NostGames KDP Tool (أندرويد)

غلاف WebView لأداة KDP، مع تشويه تلقائي للكود وبناء ملف APK عبر GitHub Actions —
بلا حاجة لأي جهاز حاسوب أو Android Studio.

## خطوات الإعداد (مرة واحدة فقط)

1. أنشئ مستودعًا جديدًا فارغًا على GitHub (خاص أو عام، حسب رغبتك).
2. ارفع **كل محتويات هذا المجلد** إلى المستودع (عبر واجهة GitHub على الويب: اسحب كل
   الملفات والمجلدات دفعة واحدة في صفحة "Add file → Upload files").
3. بمجرد الرفع، سيبدأ GitHub تلقائيًا بتشغيل خط الأنابيب (Actions) — يمكنك متابعته من
   تبويب "Actions" في المستودع.

## كل مرة تريد تحديث الأداة نفسها

- استبدل فقط الملف `web-source/kdp-tool-v2-25.html` بالنسخة الجديدة (نفس الاسم أو
  حدِّث اسمه في `.github/workflows/build-apk.yml` عند سطر `KDP_SOURCE_HTML` إن أردت
  اسمًا مختلفًا).
- ارفع التعديل (Commit) — سيُعاد تشويه الكود وبناء APK جديد تلقائيًا خلال دقائق.

## تنزيل ملف APK الناتج

1. من تبويب "Actions" في مستودعك، افتح آخر عملية بناء ناجحة (علامة ✔ خضراء).
2. في أسفل الصفحة، تجد "Artifacts" ← نزّل `kdp-tool-debug-apk` (ملف مضغوط يحوي APK
   بداخله).
3. انقله لهاتفك وثبّته (قد تحتاج تفعيل "السماح بتثبيت تطبيقات من مصادر غير معروفة"
   من إعدادات الهاتف أول مرة فقط).

## ملاحظات مهمة

- هذه نسخة **debug غير موقّعة** — تعمل وتُثبَّت مباشرة، لكنها ليست جاهزة للنشر على
  متجر Google Play (يحتاج توقيعًا رسميًا لاحقًا، خطوة منفصلة عند الحاجة).
- التشويه (Obfuscation) يطبَّق فقط على الكود داخل التطبيق النهائي، ولا يمسّ إطلاقًا
  الملف الأصلي في `web-source/` — يبقى قابلًا للتعديل والتشغيل في المتصفح كالمعتاد.
- جسر حفظ الملفات (`AndroidBridge`) يعمل فقط داخل هذا التطبيق تحديدًا؛ فتح نفس
  الملف في متصفح عادي يعمل تمامًا كما كان، بلا أي تأثير من هذا الجسر.
